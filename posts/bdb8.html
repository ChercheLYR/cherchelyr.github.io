Supplementary Exercises: Nets

We have already seen that sequences are “adequate” to detect limit points, continuous functions, and compact sets in metrizable spaces. There is a generalization of the notion of sequence, called a net, that will do the same thing for an arbitrary topological space. We give the relevant definitions here, and leave the proofs as exercises. Recall that a relation ⪯\preceq⪯ on a set AAA is called a partial order relation if the following conditions hold:

  1. α⪯α\alpha \preceq \alphaα⪯α for all α\alphaα.

  2. If α⪯β\alpha \preceq \betaα⪯β and β⪯α\beta \preceq \alphaβ⪯α, then α=β\alpha = \betaα=β.

  3. If α⪯β\alpha \preceq \betaα⪯β and β⪯γ\beta \preceq \gammaβ⪯γ, then α⪯γ\alpha \preceq \gammaα⪯γ.

Now we make the following definition:

A directed set JJJ is a set with a partial order ⪯\preceq⪯ such that for each pair α,β\alpha, \betaα,β of elements of JJJ, there exists an element γ\gammaγ of JJJ having the property that α⪯γ\alpha \preceq \gammaα⪯γ and β⪯γ\beta \preceq \gammaβ⪯γ.

  1. Show that the following are directed sets:

    1. Any simply ordered set, under the relation ⪯\preceq⪯.

    2. The collection of all subsets of a set SSS, partially ordered by inclusion (that is, A⪯BA \preceq BA⪯B if A⊆BA \subseteq BA⊆B).

    3. A collection A\mathcal{A}A of subsets of SSS that is closed under finite intersections, partially ordered by reverse inclusion (that is A⪯BA \preceq BA⪯B if A⊇BA \supseteq BA⊇B).

    4. The collection of all closed subsets of a space XXX, partially ordered by inclusion.

  2. A subset KKK of JJJ is said to be cofinal in JJJ if for each α∈J\alpha \in Jα∈J, there exists β∈K\beta \in Kβ∈K such that α⪯β\alpha \preceq \betaα⪯β. Show that if JJJ is a directed set and KKK is cofinal in JJJ, then KKK is a directed set.
